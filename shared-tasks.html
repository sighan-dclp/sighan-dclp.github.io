Evaluations

Shared tasks & bakeoffs

SIGHAN's shared-task evaluations — the bakeoffs — have supplied the field with common training and test sets, common metrics, and comparable results since 2003. Several of them, notably the word segmentation and spelling check releases, are still standard benchmarks two decades later.

2027 — Chinese document-level meaning representation parsing

The shared task of the SIGHAN-DCLP 2027 workshop: mapping Chinese documents into explicit semantic structures, over a Chinese UMR data set and a document-level Chinese AMR data set.

Using bakeoff data

The word-segmentation bakeoff releases hosted on the legacy SIGHAN site are made available for non-commercial use. Check the licence and README shipped with each release before redistributing, and cite the corresponding overview paper.
